# Mohammad Aman Ullah Khan's Portfolio

Personal academic portfolio site: research, publications, projects, and certifications.

Live at: https://mohammad-aman-ullah-khan.github.io

## Tech

Static site — plain HTML, CSS, and a small amount of vanilla JavaScript. No build step, no framework, no dependencies.

## Structure

```
.
├── index.html            # Home — about, recent news, research interest, education, teaching, skills
├── publications.html     # Published, accepted, under review, and in-preparation work
├── research.html         # Research interests, ongoing work, experience, peer review
├── projects.html         # Selected projects
├── certifications.html   # Certifications and training
├── style.css              # Shared styles
└── assets/
    ├── resume.pdf
    ├── photo.jpeg
    ├── covers/            # Journal and conference cover art / logos
    ├── certificates/      # Peer-review recognition documents
    ├── icons/             # Profile link icons
    └── projects/          # Project thumbnails
```

## Running locally

No build tools required. Clone the repo and open `index.html` in a browser, or serve the directory with any static file server, e.g.:

```
python3 -m http.server
```

## Deployment

Hosted on GitHub Pages, served from the `main` branch root.
